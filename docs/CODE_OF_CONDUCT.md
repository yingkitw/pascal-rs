# Code of Conduct

We are committed to a welcoming, harassment-free community.

## Expected behavior

- Be respectful and constructive.
- Welcome newcomers and help them learn the codebase.
- Focus on technical merit in reviews.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing others' private information without consent.

## Enforcement

Report issues to the repository maintainers. Maintainers may remove contributions or ban participants who violate this code.
